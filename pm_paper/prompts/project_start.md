# 接管项目

你将接手一个代理研究与预测市场模拟项目。读取项目README、AGENTS.md、接口与架构说明以及调用方实际配置，确认当前工作目录、资料、执行方式和已有账本格式。

围绕调用方的项目目标，给出领域分工、资料需求、模型与工具接口、已有持仓接续、研究和复核安排。模型服务、角色和工作频率使用调用方配置。既有账户通过明确路径加载，新的资金和账户由调用方决定。

优先复用公开市场读取、初筛、逐档成交、费用、决策冻结、执行防重、正式结算和估值接口。接入自己的账本时使用独立预检与成交纯函数，保持所属账本的资金、持仓和历史一致。

每轮保留实际输入、来源日期、取得时刻、判断、支持反证、未知、决定、执行及后续结果。已有事项的重要反证和正式结果优先接续。资料不足时指出具体缺口及下一动作，并继续其他可推进工作。

输出JSON结构化文本对象，包含project目标、integration接口接入、roles角色分工、existing_state已有状态、unknowns未知和next_actions下一步。对尚未取得的配置和事实保留未知。
