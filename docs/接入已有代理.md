# 接入已有代理

## 模型服务

默认适配器支持兼容Chat Completions格式的服务。修改服务地址、模型名和密钥环境变量即可复用角色提示词。各角色可通过`role_overrides`分别指定配置。

```json
{
  "role_overrides": {
    "critic": {
      "base_url": "https://your-provider.example/v1",
      "model": "your-review-model",
      "api_key_env": "REVIEW_MODEL_KEY"
    }
  }
}
```

该片段合并进项目配置。密钥由运行环境提供，运行数据保存在调用方指定目录。

## 原生命令行代理

为已有代理写一个小适配程序，从标准输入读取JSON结构化任务，将最终结构化交付写到标准输出。输入包含角色、系统提示词、具体任务和实际上下文。工具日志可写到标准错误。

```json
{
  "type": "command",
  "command": ["python", "examples/native_agent_adapter.py"],
  "timeout_seconds": 120
}
```

将上述对象作为项目配置的`agent`字段。命令以明确的参数数组启动。示例适配程序用于检查交接格式，实际模型和工具调用由使用者接入自己的代理程序。

## 已有Python代理

```python
from pm_paper.workflow import run_cycle

class MyAgent:
    def run(self, role, task, context, directory):
        return my_existing_agent(role, task, context, directory)

result = run_cycle(config, catalog, "runtime/project", agent=MyAgent())
```

原生代理也可以直接读取`pm_paper/prompts`中的提示词，再通过独立预检、账本及公开读取接口完成项目。运行记录由所属代理和项目按真实任务保存。

## 已有数据和账本

公开行情读取可替换为提供同样`snapshot(market_ids)`方法的客户端。已有新闻或领域数据库可按事件和资料范围导出上下文，附来源日期和实际取得时点。

已有其他格式账本可先使用`preflight`及成交纯函数，通过所属账本的事务、决定标识和报价原件保存结果。原有状态、资金与历史按所属账本继续接续。
